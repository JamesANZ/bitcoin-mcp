# Bitcoin MCP tools

| Tool | Use it for |
| --- | --- |
| `get-address-stats` | Funded and spent amounts, and transaction counts, for one address |
| `get-address-transactions` | Transaction history for one address |
| `get-address-utxos` | Unspent outputs for one address |
| `get-transaction` | One transaction by txid |
| `get-block` | One block by height (`block_height`) |
